## 2. 硬件事实核对

### 2.1 开发板（ESP32-P4-Module V1.3）电源架构

```
Type-C #1 (TYPEC-16P, CC1/CC2 各 5.1k 下拉 = 纯受电 UFP，无 PD)
        │ VBUS
        ▼
   VIN1_5V ──┐
             ├── U1 LM66200DRLR (双路理想二极管 ORing，反向阻断) ──► VIN_5V
Type-C #2    │                                                        │
        │ VBUS                                                         ├──► Buck 5V→3.3V (ETA3485/SY8088/RY3420/TLV62569) ──► +3V3
        ▼                                                                │
   VIN2_5V ──┘                                                           ├──► SY7200 Boost ──► BOOST_BLK / VLED+ (屏背光)
                                                                         ├──► U12 MT9700 (可调限流功率开关) ──► USB5V ──► USB-A 口
                                                                         └──► LDO ──► VCC1V8 / VCC2V8 (MIPI/摄像头)
```

**关键事实**：
1. 两个 Type-C 都是 **16Pin 纯充电/受电口**，CC 上只有 5.1k 下拉电阻，**没有 PD 控制器、没有 CC 逻辑芯片**。→ 扩展板若要 PD 快充，需自建 PD Sink（如 CH224K/HUSB238/IP2726）。
2. `VIN_5V` 是 LM66200 的**输出节点**，本身适合被外部注入（LM66200 具备反向阻断，不会倒灌回 Type-C VBUS）。
3. `+3V3` 是 Buck 输出节点，**不可注入**。
4. USB-A 口由 MT9700 限流供电，与本项目无关，但说明板上 5V 总线的限流设计已有先例。

## 4. 关键冲突与设计约束（必须先解决）

### C1. 功率流方向与"J4/J2 供电"的物理边界
开发板 3.3V 域由板上 Buck 产生，**没有外部 3.3V 输入口**。所以"电池通过 J4/J2 给开发板供电"只能解释为：
**电池 → DC-DC 升到 5V → 注入 `VIN_5V`（J2-1/2、J4-1/2）**。
反向（开发板给电池充电）也只能是：**`VIN_5V` 取电 → 降压/线性充电 → 电池**，即"从 5V 母线取电充电"，而不是"从某个 BAT 脚充电"。

### C2. 双向同时工作的死锁
若 Type-C 插在**扩展板**上给电池充电，同时电池又在给 `VIN_5V` 供电，则形成"自己的 5V 给自己的充电器供电"的环路。必须用 **Power Path（电源路径管理）** 明确优先级：`USB 在场 → 系统由 USB 直供 + 电池充电；USB 拔除 → 电池升压接管`，且两路之间必须有理想二极管隔离。

### C3. 2.54mm 排针的载流能力
单脚 2.54mm 排针（典型 3A 额定，实际建议 ≤2A/脚，温升 30℃）。
- `VIN_5V` 共 4 脚 → 建议总电流 ≤6A，**设计目标 3A** 留 2 倍余量。
- `GND` 共 4 脚 → 同上。
- 若整机 5V 峰值 >3A，**必须增加独立大电流连接器（XT30/接线端子）**，不能只靠排针。

### C4. Strapping 脚禁忌
J2-21/22/23/24 = GPIO36/37/34/35（P4 Strapping）。扩展板在此四脚上**只能高阻**，否则无法启动或无法进下载模式。

### C5. 电池化学与串数未定
1S（3.7V/4.2V）与 2S（7.4V/8.4V）在拓扑、保护、充电器、升压比上完全不同：
- 1S → 需 Boost 到 5V（3.0V 时升压比 1.67，输入电流是输出的 1.7 倍，**大电流难点**）；
- 2S → 需 Buck 到 5V（效率高、电流小），但需要 2S BMS + 平衡。

## 7. 风险清单

| # | 风险 | 等级 | 缓解措施 |
|---|---|---|---|
| R1 | 电池无保护 IC 直接接排针 → 短路起火 | **极高** | 强制"保护 IC + 二次保护(PTC/保险丝) + 充电器限压限流 + NTC"四重；电池接口用带保护的成品电池包 |
| R2 | 向 `+3V3` 倒灌损坏板上 Buck | **高** | 硬件上把 J4-5/6 设计为"只检测不输出"（串 100k 分压 + 明确的 DNP 跳线） |
| R3 | 1S 升压 3.8A 输入电流超出电芯能力 → 电压塌陷 → P4 复位 | **高** | 电芯选 ≥3C 放电，或改 2S；加输入欠压锁定（UVLO）+ 大容量输入电容 |
| R4 | 排针接触电阻/温升导致 5V 跌落 | 中 | 4 脚并联 + 每脚 ≤2A + PCB 上大面积铺铜 + 实测温升 |
| R5 | 边充边用时电池反复充放（无 power path） | 中 | 必须用带 power path 的充电器，或用理想二极管做负载分配 |
| R6 | 外壳内腔未知 → PCB 装不进去 | **高** | 外形未确认前不出 Gerber；先做 3D 打印"假板"验证 |
| R7 | 热：充电 IC + Boost 集中在 86×86 小空间内 | 中 | 热仿真/实测；充电电流降到 1A 以下；外壳开散热孔 |
| R8 | BOM 缺 ESD → Type-C 口打静电损坏 | 中 | 补 USBLC6-2SC6 + PESD5V0 |
| R9 | Strapping 脚被扩展板拉动 → 无法启动 | 中 | 设计评审时逐脚核对 J2-21/22/23/24 |
