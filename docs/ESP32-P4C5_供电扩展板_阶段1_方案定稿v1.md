## 0. 三分钟看懂这块板

**它是什么**：一块 52×72mm 的 4 层小板，与开发板同尺寸同安装孔，用 4 根 M3 铜柱叠在开发板背面，线束接到 J4。它给开发板供 5V，同时管一块 1S 电池（锂离子或锂聚合物均可）的充电、保护、计量。

**电流怎么走**（记住这一句就够）：

```
电池 → 保护 FET → 开关充电器(Power Path) → SYS(3.7V) → 升压到 5V → 理想二极管 → 开发板 VIN_5V
                                                              ↑
                       板载 Type-C 5V → 保险丝 → 理想二极管 ──┘（插电时走这条，升压自动关掉）
```

**一句话概括设计取舍**：能用开关电源就不用线性，能用硬件保护就不用软件保护，能在 5V 侧加二极管就不让电流反向流动。

## 1. 我替你定的 8 个决定

| # | 问题 | 我的决定 | 理由 | 代价 / 风险 |
|---|---|---|---|---|
| D1 | 功率流 | **单向 + 边充边用**。不做"电池当充电宝对外输出 5V" | 你要的是"内置电池续航"，不是充电宝。加双向要双向 Buck-Boost + VBUS 开关 + 插拔检测，成本翻倍、风险翻倍 | 不能拿它给手机充电 |
| D2 | 电池 | **1S（单节）锂离子/锂聚合物**，3.7V 标称 / 4.2V 满 / 2.8V 切，容量 3000~5000mAh，放电 ≥3C | 1S 配升压最简单、保护电路最成熟便宜；2S 要多一颗平衡 BMS | 1S 大电流时电池侧要 3.4A，电芯必须 ≥3C |
| D3 | 充电口 | **扩展板自带一个 Type-C 专门充电**；开发板原有 Type-C 只保留"供电/烧录" | 开发板的 VIN_5V 是双向节点，从它取电再充电会形成环路。分开最干净 | 机壳要开两个 Type-C 孔（或只开扩展板那个） |
| D4 | 充电方案 | **BQ25606**（开关型 3A，带 Power Path），**不用 BOM 里的 TP4056 / IP5306** | TP4056 是线性，1A 时白烧 0.8W 且没有路径管理（充满后负载还在吃电池）；IP5306 静态电流 >50µA，长期待机把电池耗干 | BQ25606 是 QFN，需嘉立创 SMT；单颗约 7 元 |
| D5 | 升压 | **TPS61088**（5V/3A） | 3.0V 输入也要扛 2.5A 输出，只有 10A 开关的料才稳 | QFN-20，需散热过孔 |
| D6 | 电源切换 | **两颗 LM74700-Q1 + N-MOS 做理想二极管 ORing**，不用肖特基 | 肖特基在 2A 时白掉 0.8W，小壳子里散热扛不住；理想二极管压降只有 20mV 量级 | 多两颗 IC，多 4 个元件 |
| D7 | 升压开关控制 | **升压 EN 直接接充电器的 /PG 脚** | USB 在场 → /PG 拉低 → 升压停；USB 拔掉 → /PG 悬空被上拉 → 升压启动。一颗电阻搞定，失效时也不会两路对打（因为后面还有理想二极管） | /PG 逻辑反了就会"边充边放"，需在样机验证 |
| D8 | 板型 | **82×72mm 双层堆叠板，直接插在 J2/J4 上**，单面布件（元件面朝外） | 68 个脚只有插针方案最可靠；排线方案在小壳子里塞不下 | **必须先量 3 个尺寸**（见 §7），否则不出 Gerber |

## 2. 系统架构

### 2.1 功能块

| 块 | 内容 | 关键器件 |
|---|---|---|
| B1 输入 | Type-C 16P、CC 5.1k 双下拉、ESD、TVS、3A 保险丝 | J1 / U1 USBLC6 / D1 SMBJ5.0A / F1 |
| B2 充电 | 5V→4.2V 开关充电，1A，Power Path，NTC 温控 | U2 BQ25606 + L1 1.5µH |
| B3 保护 | 低边双 FET 一次保护 + 5A 熔断二级保护 | U3 S-8261 + Q1 8205A + F2 |
| B4 计量 | I²C 电量计，SOC + 低电量中断 | U4 MAX17048 |
| B5 升压 | 3.0~4.4V → 5.0V/2.5A | U5 TPS61088 + L2 4.7µH |
| B6 切换 | 双路理想二极管 ORing + 电平适配 | U6/U7 LM74700 + Q2/Q3 NCE3080K |
| B7 输出 | TVS、储能电容、双色指示灯 | D2 / C15 / LED1-2 |
| B8 接口 | 电源 2×2P + 信号 1×6P 线束座 | J5 / J6 |

### 2.2 四种工况（这张表就是全部行为定义）

| 工况 | 条件 | 开发板 5V 来自 | 电池 | 升压 | 指示灯 |
|---|---|---|---|---|---|
| **A 插电 + 有电池** | 扩展板 Type-C 插入 | **USB 直供**（经理想二极管） | 充电中（1A，受温度限制） | **关断** | 红亮（充电）/ 充满转绿 |
| **B 插电 + 无电池** | 电池拔掉 | USB 直供 | — | 关断 | 绿亮 |
| **C 不插电** | 仅电池 | **升压 5V** | 放电 2.8~3.4A | 开启 | 绿亮 |
| **D 插开发板 Type-C** | 只插开发板的口 | 开发板自己的 LM66200 供 | **不充电**（但也绝不倒灌） | 关断 | 绿亮 |

> 工况 D 是刻意设计的：开发板自己的 Type-C 仍然能单独点亮整机（烧录、调试时用）。这时扩展板只是"挂在那里"，靠理想二极管阻断反向电流。

### 2.3 三处必须存在的"隔离"

1. **Type-C VBUS 与电池之间**：BQ25606 的 BATFET + 外部保护 FET，双向都断得开。
2. **升压输出与 USB 5V 之间**：两颗 LM74700，谁高谁导通，另一边反向截止。
3. **`+3V3`（J3-5/6）**：**只接 10k 上拉电阻**（给 I²C 用，电流 µA 级），绝不作为电源。这条要写进 PCB 的丝印和装配说明。

## 3. 保护策略与阈值

四层防护，任何一层失效都还有下一层：

```
第1层 充电器限压限流（BQ25606：4.2V±1% / 1A / 输入1.5A / 温度窗口）
第2层 电池一次保护（S-8261 + 8205A：过充4.30V / 过放2.80V / 过流8~12A / 短路<1ms）
第3层 硬熔断（F2 5A、F1 3A，不可恢复）
第4层 系统级（升压过流打嗝、输出 TVS 钳位、ESD）
```

| 保护项 | 阈值 | 由谁实现 | 恢复方式 | 验证方法 |
|---|---|---|---|---|
| 电芯过充 | **4.30V ±0.05V** | S-8261 | 降到 4.10V 自动恢复 | 直流源慢升压至 4.35V，看 FET 是否切断 |
| 电芯过放 | **2.80V ±0.08V** | S-8261 | 充到 3.0V 恢复 | 电子负载放电至 2.7V |
| 放电过流 | **8~12A**（由 8205A 的 Rds 决定） | S-8261 | 移除负载 | 电子负载阶跃，示波器看切断时间 |
| 输出短路 | **<1ms 切断** | S-8261 | 移除短路 | 直接短接电池输出（串 10mΩ 采样） |
| 充电电流 | **1.0A ±10%** | BQ25606（ICHG 电阻） | 自动 | 电流表串入 |
| 输入限流 | **1.5A** | BQ25606（ILIM 电阻） | 自动 | 5V 电源看限流点 |
| 充电温度窗口 | **<0℃ 或 >45℃ 停充**，回滞 5℃ | NTC + TS 分压 | 回到窗口内自动续充 | 冷热风枪 + 热电偶 |
| 电芯硬短路 | **5A 熔断** | F2 | 永久（换板） | 不做破坏性测试，抽检 1 片 |
| 输入过流 | **3A 熔断** | F1 | 永久 | 同上 |
| 5V 输出过压 | **5.6V 钳位** | TPS61088 内部 OVP + D2 | 自动（打嗝） | 断开反馈电阻模拟 |
| 5V 输出过流 | **≈3.2A 输入侧限流** | TPS61088 ILIM | 打嗝 | 电子负载拉满 |
| CC 脚 ESD | **±8kV 接触** | USBLC6-2SC6 | — | ESD 枪打 CC1/CC2 |

**不允许的做法（设计禁令）**

- ❌ 电池直接并联到 J2/J4 的 `VIN_5V`
- ❌ 从 J3-5/6（`+3V3`）取电给任何负载
- ❌ 用软件（P4 的 GPIO）作为唯一的手段去切断电池
- ❌ 在 J2-21/22/23/24（GPIO36/37/34/35，Strapping 脚）上挂任何低阻

## 4. 功率与热

### 4.1 预算

| 工况 | 5V 输出 | 电池侧电流 | 板内耗散 | 续航（5000mAh） |
|---|---|---|---|---|
| 待机（屏亮、WiFi 空闲） | 0.5A / 2.5W | 0.75A | 0.25W | ≈20h |
| 典型（屏亮 + 相机 + WiFi） | 1.2A / 6W | 1.8A | 0.6W | ≈7h |
| 满载（屏最亮 + 喇叭 + WiFi 发射） | 2.0A / 10W | 3.0A | 1.0W | ≈5h |
| 瞬时峰值（<10s） | 2.5A / 12.5W | 3.4A | 1.3W | — |
| 仅充电（系统关机） | 0 | 1.0A 充 | 0.4W | 5h 充满 |

> 续航按 5000mAh×3.7V×90% 估算，实际以实测为准。3000mAh 电芯按比例打 6 折。

### 4.2 热设计要点

- 三颗主要发热源：BQ25606（0.4W）、TPS61088（0.5W）、8205A（0.4W），总 1.3W 集中在 60×40mm 内。
- 三颗都要求 **EP 焊盘下 3×3 个 0.3mm 过孔** 打到内层地平面，顶层铺铜 ≥100mm²。
- 8205A 在 3A 时 0.4W，SOP-8 温升约 40℃，允许但要注意：**持续 3A 以上建议换 2 颗 NCE3080K**（BOM 里有，4mΩ）。
- 外壳是密闭的，1.3W 会让内部升 8~12℃。**充电时不要放在被子里**——这是唯一需要用户配合的事。

---

### 4.3 电池选型：锂聚合物可以吗

**可以，电气上完全等效。** 1S 锂离子（18650/21700）与 1S 锂聚合物（软包）是同一套化学体系、同一条充电曲线：

| 参数 | 两者相同 | 说明 |
|---|---|---|
| 标称电压 | 3.7V | — |
| 满充电压 | **4.2V** | CC/CV，截止电流 0.1C |
| 放电截止 | 2.8V（本板设定） | 不要放到 2.5V 以下 |
| 充电方式 | 恒流→恒压 | BQ25606 直接支持 |

**唯一不能踩的坑**：BQ25606 的充电电压是**出厂固定 4.2V**，所以电芯必须选 4.2V 截止的常规型号。市面上有 4.35V / 4.4V 的"高压电芯"（同体积多 5~8% 容量），**不能用**——充不满是小事，充满判定错了会一直涓流，电芯发热。

**软包 vs 圆柱，真正的差别在机械**：

| | 软包（锂聚合物） | 18650 圆柱 |
|---|---|---|
| 形状自由度 | 高，可做 5mm 薄片贴在外壳内壁 | 固定 65×18.4mm，塞不进 21.5mm 深的壳 |
| 抗滥用 | 差，怕穿刺/挤压/鼓包 | 好，有钢壳 |
| 需要支撑 | **必须**，泡棉+双面胶固定，不能悬空 | 电池座即可 |
| 本方案适配 | ✅ 推荐（3000~5000mAh，如 605080/705080） | ❌ 装不进壳 |

**选型清单（照着买）**

1. 1S 软包，标称 3.7V、满充 **4.2V**
2. 容量 3000~5000mAh（对应续航 5~20 小时，见 §4.1）
3. **持续放电 ≥3C**（5000mAh 就是 ≥15A；这条比容量重要）
4. **自带保护板**最好；没有也行，本板有 S-8261 一次保护
5. 出线 **JST-PH2.0 2P**，线长 60~100mm，红正黑负
6. 附带或另配 **10k B3950 NTC**，用高温胶带贴在电芯大面中央

**装配红线**

- 软包电芯**不得压在螺丝柱、焊点、排针**上，否则长期震动会刺穿铝塑膜
- 电芯与 PCB 之间垫 1mm 泡棉，四周留 1mm 膨胀余量（软包用久了会鼓 5~8%）
- JST-PH 座有方向但**没有反接保护**，插之前看红黑线
- 不要用带铝塑膜破损、鼓包、零电压的电芯

### 5.1 建议分页

| 页 | 内容 | 网络数 |

| P6 | 接线座 J5/J6 + 测试点 | SYS_5V / GND / 3V3_EXT / SDA / SCL |

### 5.2 网表

- 完整逐脚网表：`docs/hw/netlist_v1.csv`（网络 / 位号 / 引脚，可直接对照画图或导入）
- 按网络分组的速查版：`docs/hw/netlist_by_net.md`（45 个网络）
- 元件清单：`docs/hw/bom_v1.csv`（64 个位号）

**画图时最容易错的 6 个点**（我已按正确接法写进网表）

1. BQ25606 的 **D+/D-** 必须接到 Type-C 的 D+/D-。不接的话芯片会按 USB100（500mA）限流，充电慢一半。
2. 控制升压启停的是 **`PG_N` 直接进 TPS61088 的 EN**，中间不要加反相器。
3. `STAT_N` 上串 **1kΩ** 再进 P4（R18），因为它被 LED 拉到 3.1V。
4. `PG_N` 是 4.4V 电平，进 P4 前必须过 **100k/220k 分压**（R16/R17），不能直连。
5. 保护 FET 在**低边**：`BAT_C_N → FET → GND`，`U3.VSS = BAT_C_N`，`U3.VM` 经 2k 到 GND。
6. 电量计的 I²C 上拉接 **`3V3_EXT`（J3-5/6）**，不是接电池，也不是接 5V。

## 6. PCB 设计规则

### 6.1 叠层（嘉立创 4 层，1.6mm，JLC7628）

| 层 | 用途 |
|---|---|
| L1 顶层 | 元件面 + 主要功率走线（SYS_V / SYS_5V / BAT_P） |
| L2 | **完整地平面**（不分割） |
| L3 | 电源平面（5V 与电池分两块，各占一半） |
| L4 底层 | 排母焊盘 + 少量信号（I²C/状态线） |

### 6.2 载流线宽（1oz，温升 10℃，IPC-2221）

| 电流 | 外层宽度 | 内层宽度 | 过孔数（0.3/0.6mm） |
|---|---|---|---|
| 1A | 0.5mm | 1.0mm | 2 |
| 2A | 1.0mm | 2.0mm | 4 |
| 3A | 1.5mm | 3.0mm | 6 |
| 4A | 2.1mm | 4.2mm | 8 |

功率路径一律**铺铜不用细线**，并且每个功率节点至少 4 个过孔换层。

### 6.3 其他硬规则

| 项 | 要求 |
|---|---|
| 最小线宽/间距 | 0.15/0.15mm（嘉立创标准工艺），电池侧间距 ≥0.3mm |
| 板框 | 82×72mm，四角 R3，板厚 1.6mm，**四角 M2.5 安装孔（孔径 2.7mm，禁布区 5mm）** |
| 排母定位 | 2×17P，脚距 2.54mm，**位置见 §7 待实测** |
| 元件高度 | 顶面 ≤4.5mm（Type-C 3.4 / 电感 4.0 / TO-252 2.3）；底面只有排母（8.5mm） |
| 丝印 | 电池 `+`/`−` 大字、`5V OUT → 开发板`、`仅充电口`、`+3V3 仅检测` 警示 |
| 防呆 | 电池座用 JST-PH（带卡扣，不会插反）；排母与开发板排针一一对应，反插会顶住 |
| ESD | Type-C 的 CC/DP/DN 全部先进 USBLC6 再进芯片 |

### 6.4 布局分区（从左到右）

```
[Type-C + ESD + 保险丝] → [BQ25606 + L1] → [TPS61088 + L2] → [双 ORing + 输出]
                              ↓                    ↓              ↓
                        [电池座 + 保护 + 电量计]  [测试点]      [排母 J2/J3]
```

- 两个电感（L1/L2）**转 90° 错开**，避免磁场耦合。
- 电池座和 Type-C 放在板的两端，中间用保护器件隔开。
- 电量计尽量靠近电池座（走线短、抗干扰）。

## 7. 机械与外壳（已查到官方尺寸，v1.1 已据此改板）

### 7.1 官方尺寸（2026-11-21 从 gitee/osptek 仓库取得）

来源：`gitee.com/osptek/esp32-p4c5-module-dev-board` → `images/dimensions.png`（机械尺寸图）。

| 项 | 数值 | 备注 |
|---|---|---|
| 开发板外形 | **52.00 × 72.00 mm** | 之前按原理图推算的 82×72 **是错的** |
| 安装孔中心距 | **46.15 × 66.16 mm** | 左右各内缩 2.925mm、上下各内缩 2.92mm |
| 安装孔 | **M3**（Ø3.2） | 四角，带禁布区 |
| 排针 | 2 组 2×17P，2.54mm | **在两条 72mm 长边上**，不在上下边 |

> 同批取得 `ESP32-P4C5-Module_Schematic_V1.5.pdf`：已核对，J2/J4 的图面坐标与 V1.3 完全一致（336.0,554.3 / 336.0,411.9），说明 **§2.2 的 68 脚引脚表在 V1.5 上依然有效**。V1.5 的改动是增加 C5/C6 BOOT 跳线。

### 7.2 为什么改用线束连接（v1.1 的核心变更）

官方仓库里确实有底板 PCBA 的 STEP（`docs/ESP32-P4C5-Module_Carrier_V1.5.step`，25MB），但：

- gitee 对大于 5MB 的文件要求登录后才给下载；
- github raw 域名在本机不可达，API 下载 300 秒只拿到 10MB。

所以**两排排针的横向间距（X 坐标）仍无法确证**。而 2×17 排母是刚性件，X 偏 1.27mm 就完全插不进去。

**结论：放弃排母直接堆叠，改用线束。** 这是唯一只依赖已确认尺寸（52×72 + 4 个安装孔）的方案：

| 连接 | 方式 |
|---|---|
| 5V / GND | J5（2×2P 2.54）→ 4 根 22AWG 线 → 开发板 J4-1~4 |
| +3V3 / I²C / 状态 | J6（1×6P 2.54）→ 6 根线 → 开发板 J4-5/6、19、31~34 |

**收益**：① 100% 可装配；② 堆叠高度从 16.2 降到 **15.7mm**；③ 板子按 4 个 M3 孔自由定位，不必卡在排针上。

**代价**：多一组线束，装配多 2 分钟；外观不如直接堆叠整齐。

### 7.3 堆叠高度核算（v1.1）

| 层 | 厚度 |
|---|---|
| 开发板 PCB | 1.6 |
| M3 铜柱 | 8.0 |
| 扩展板 PCB | 1.6 |
| 元件（最高 Type-C 3.4 / 电感 4.0） | 4.5 |
| **合计** | **15.7mm** |

后壳内深 21.5mm，**余量 5.8mm**。超差时：铜柱换 5mm（省 3mm），或后壳加垫圈。

### 7.4 仍需你确认的两件事（已不再是阻塞项）

| # | 事 | 为什么不再阻塞 | 怎么解决 |
|---|---|---|---|
| M1 | 开发板背面最高元件（TF 座、MIPI FPC）会不会顶到扩展板 | 铜柱 8mm 远高于它们（最高约 3mm） | 装机时看一眼 |
| M2 | 后壳是否够深 | 15.7 < 21.5 | 盖上试一次 |

## 9. 测试计划与验收标准

样机回来按这个顺序做，**第 1 项不过就不要做第 2 项**。

| # | 测试项 | 方法 | 通过判据 |
|---|---|---|---|
| T1 | 静态阻抗 | 万用表量 VBUS_IN↔GND、SYS_5V↔GND、BAT_P↔GND | 均 >10kΩ（无短路） |
| T2 | 空载上电 | 限流 100mA 的 5V 电源接 J1 | 电流 <20mA，无发热，绿灯亮 |
| T3 | 充电 | 接 3.7V 模拟电池（直流源串 10Ω） | 充电电流 1.0A±10%，红灯亮，SYS_V ≈4.4V |
| T4 | 充满转灯 | 电池升到 4.2V | 电流降到 <100mA，红灯灭/绿灯亮 |
| T5 | 过充保护 | 直流源直接给 BAT_P 升到 4.35V | 保护 IC 在 4.25~4.35V 切断 |
| T6 | 过放保护 | 电子负载放 BAT_P 到 2.75V | 在 2.72~2.88V 切断 |
| T7 | 短路保护 | 短接 SYS_5V 到地（串 10mΩ 采样） | <1ms 切断，撤除后自恢复 |
| T8 | 升压效率 | 电池 3.7V，输出 2A | 效率 ≥88%，输出电压 5.0V±3% |
| T9 | 切换 | 带载 1A 时插拔 Type-C | 输出不掉超过 200mV，不重启 |
| T10 | 反灌 | 只插开发板 Type-C，测扩展板电池侧电流 | <1mA（不反灌） |
| T11 | 温升 | 满载 30 分钟 | 电感 <80℃，8205A <75℃，外壳内 <55℃ |
| T12 | 电量计 | I²C 读 0x36/0x37 | SOC 与实测电压偏差 <5% |
| T13 | 装配 | 插上开发板、装壳 | 无干涉，排针不歪，Type-C 对得上孔 |

**验收结论口径**：T1~T13 全过 = 可小批量；T5/T6/T7 任一不过 = 安全不合格，必须改板。

## 10. 剩余风险（我知道但我改不了的）

| 风险 | 为什么还在 | 兜底 |
|---|---|---|
| **R1 排针间距未实测** | 原理图不按比例画，我只能推算 | 出 Gerber 前必须量；量不了就先打一块"只有排母的定位假板"试插 |
