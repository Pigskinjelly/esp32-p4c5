## 第三轮：音乐播放体验 / 歌词 / 自检转圈 / 稳定性 / 设置滚动 / 相机方向

### 1. 音乐：网络播放的进度、时长、暂停（ui_app_music.c）
- `stream_http_mp3()` 之前**完全没更新** `s_pos_ms/s_total_ms`，所以界面一直 0:00。
  现在按解码样本累加 pos，用 `Content-Length × 8 / bitrate` 估总时长。
- 新增 `s_paused`：暂停时不读不写但保持 HTTP 连接（解码循环里也检查，暂停更跟手）；
  `play_btn_cb` 对网络源走 s_paused 切换，之前它直接进 `s_count==0` 分支 return（点了没反应）。
- 去掉界面两句"把 .mp3 …放到 SD 卡"提示；`s_count==0` 时不再显示任何提示。

### 2. 歌词（不要圆圈）
- 唱片圆圈换成 440x186 歌词面板，5 行：中间高亮、上下淡色。
- 来源：网易云搜索取 song id → `api/song/lyric` 取 LRC（免登录，HTTP）。
  **坑**：`songs` 后第一个 `"id"` 是 album/artist 的（0 或专辑 id），必须用 `"mvid"` 做锚点。
  另：无版权歌返回 `[00:00.000]暂无歌词`，当无歌词处理。
- LRC 解析：反转义 `\n` → 按行取 `[mm:ss.xxx]`，2 位小数按厘秒、3 位按毫秒；
  文本用 `trim_utf8_tail()` 防切半个汉字，显示时过 `ui_font_safe()`（缺字形变 '?' 不是方框）。

### 3. 自检转圈更顺
- `lv_spinner` → 自绘 `lv_arc` + 1500ms/360° 线性无限循环动画（`boot_spin_exec`），
  只刷圆弧；删除前 `lv_anim_delete()`。

### 4. 卡顿/重启（真机复现思路）
- 空闲 394s 不重启、heap 稳定 → 重启发生在"搜歌打字"时。
- 根因：每敲一个键都 `search_rebuild()`（本地最多 80 行）+ 候选条最多 72 个字，
  一次几十个 LVGL 对象反复建删，内部 RAM 碎片化 → OOM assert。
- 修法：`search_rebuild` 改成脏标志，tick（480ms）里节流重建；本地结果 80→6 行；
  候选字 72→24；三个 `ui_keypad_bind` 统一用 `search_mark_dirty`。

### 5. 设置页可上下滑动
- 内容放进 480x480 竖向滚动容器（透明底 + 细滚动条），重启按钮移到内容末尾跟着滚。

### 6. 相机镜像 / 180°
- `sdkconfig` 关掉 `CONFIG_EXAMPLE_ENABLE_CAM_SENSOR_PIC_VFLIP/HFLIP`（硬件镜像，用户看到的就是它）。
- 新增 `s_cam_rot_off`（NVS `sys/cam_rot`，默认 180，补偿结构件里翻转安装的摄像头），
  PPA 角度 = 屏幕方向 + 补偿；相机 App 加「画面」按钮（0/90/180/270 循环），点一下就能校到正。
- 预览与照片共用同一角度，"所见即所得"。

### 7. 顺手修的坑
- 设备 DNS 经常 `getaddrinfo 202`（搜歌/天气时好时坏）→ 拿到 IP 后设固定 DNS
  （223.5.5.5 / 119.29.29.29）。
- 构建偶发卡死（DLP 加密驱动）：gcc 进程 0% CPU 卡在某个 .obj，`Stop-Process` 后重跑；
  用 `CMAKE_BUILD_PARALLEL_LEVEL=2` 明显更稳。

### 8. 已知限制（要告知用户）
- 酷我对 VIP 歌只给 ~11s 试听（`天外来物` 返回 181KB；免费歌 `稻香` 3.35MB 完整）。
  不是播放器的 bug，是版权限制。

## 第四轮：后台开关/内存、歌词、音质、自检同步、方框、去电台

### 1. 多开卡顿 → 后台开关 + 退出即释放（ui_shell.c / ui_app_settings.c）
- 新增 `s_app_bg` 位图（NVS `sys/app_bg`）：`ui_shell_app_bg/set`；默认全关。
- `ui_shell_back_event_cb()`：后台关 → `lv_obj_delete(s_app_container[idx])` 并置 NULL/未创建，
  下次进入重建；后台开 → 只隐藏。设置-应用管理每行改为 **运行 / 后台** 两个开关。
- 关键修复：`ui_shell_preview_attach()` 现在给图片挂 `LV_EVENT_DELETE` 回调把自己从
  `s_listeners` 摘掉，并复用空槽位——否则销毁相机/监控界面后定时器会往已释放对象 set_src 崩溃。
- 实测：依次开关 8 个 App，heap_int 稳定在 ~150KB（此前只涨不落）。

### 2. 歌词（已验证可用）
- 根因就是上一轮的 id 解析：`songs` 后第一个 `id` 是 album 的。用 `"mvid"` 做锚点后
  取到 1463165983，LRC 46 行正常。
- 界面：5 行歌词、中间高亮；无歌词显示"暂无歌词"。

### 3. 音质（滋啦电流声）
- `app_audio_out_write()` 之前直接返回 `esp_codec_dev_write()` 的返回值，
  写不完的部分被丢掉 → 周期性爆音。改成循环写满。
- I2S DMA 加深：`dma_desc_num=8, dma_frame_num=256`。

### 4. 开机自检与锁屏同步
- 检查项等待缩短（相机 4.5s、网络 2s），全部完成后**等锁屏时间就绪**再淡出
  （`ui_shell_lock_ready()`：锁屏时间不是 "--:--"），最多再等 6s，期间提示"正在同步锁屏信息…"。
- 天气没到时锁屏显示"天气加载中"而不是"天气数据未获取"。
- 天气 `weather_start()` 加 static 保护：以前每次进 App 都新建 8KB 任务 → 内部 RAM 被吃掉几十 KB。

### 5. 方框问题（这次找到真正的判断方法）
- 字体是 4 个 cmap：ASCII / 167..36127 sparse / 36129..36145 / 36148..65311 sparse。
  用 `unicode_list_1/3` 里的偏移（相对 range_start）判断字形是否存在，脚本扫描所有字符串：
  **只有 ✓ ✗ 缺字形**（`--symbols` 注释里列了但生成时没进去）。
- 自检项前缀改成文字"正常/异常/检测中"（不再用 ✓✗…）。
- "拼音"提示框用了 `lv_font_montserrat_16`（无汉字）→ 改 `ui_cjk_16`，这就是搜索框方框。
- 结论：以后新增中文一律 `ui_cjk_16`；符号只用 ASCII 或已验证存在的（。、…·×°→）。
