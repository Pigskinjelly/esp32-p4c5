# 2026-11-11

## ESP32-P4C5 网络监控设备（esp32-p4c5-ipcam）

- 新建工程 `esp32-p4c5-ipcam`（从 `esp32-p4c5-demo` 复制，复用已验证的 I2C/ST7102/ES8311 代码）。
- 硬件基线确认：板卡 V1.5；屏 YDP395BT008-V1（3.95" 480×480，MIPI-DSI 2-lane，ST7102）；
  摄像头 SC2336（2-lane CSI，24MHz 板载晶振）；16MB Flash + 32MB PSRAM。
- C5↔P4 内部 SDIO：P4 GPIO14–19（D0-D3/CLK/CMD），C5CHIP_PU←GPIO54，C5 GPIO2↔P4 GPIO6。
- 关键 GPIO：LCD_RST=5、LCD_TE=4、背光=20、CSI_RST=26（1.8V 开漏）、PA_EN=53、
  I2S MCLK/BCLK/WS/DOUT/DIN=13/12/10/9/11、I2C=7/8。

### 代码
- `app_lcd.c` 重写：480×480 / 620Mbps / 官方 init_cmds；**ST7102 在 new_panel 时会读 ID，
  必须先释放 LCD_RST**，否则 DBI 读 FIFO 卡死。
- `main.c`：CSI 输出 YUV420；PPA YUV420→RGB565 等比缩放 800×800→480×480 送屏。
- 新增 `app_encoder.c`：`/dev/video11` V4L2 M2M，OUTPUT 用 USERPTR 实现零拷贝喂 VPU。
- 新增 `rtsp_server.c`：RTSP/RTP over UDP + TCP interleaved，FU-A 分片，SDP 带 sprop。
- 架构文档：`docs/ARCHITECTURE.md`；工程说明：`esp32-p4c5-ipcam/README.md`。

### 环境问题（重要）
- 本机文档加密驱动 **TFsdframe / TsdEncrypt**（TEC Solutions Ocular 3）会加密 CMake/ninja
  子进程写出的文件，桌面目录里 CMake 产物文件头为 `%TSD-Header-###%`，导致 gcc 汇编报
  `junk at end of line, first unrecognized character is '%'`。
- **突破**：加密与否取决于进程树的根。由 `bash.exe` / `cmd.exe` 启动的 gcc/ar 产物是明文；
  由 `powershell.exe` 启动的会被加密。因此日常构建必须走 `bash build.sh`（cmake --build）。
- 关键配置：`TMP/TEMP=D:\idftmp`（不要用 C 盘 Temp）、`-DCMAKE_C_FLAGS=-pipe`、
  禁用 ccache（`IDF_CCACHE_ENABLE=0`）、`IDF_SKIP_TRY_COMPILE=1`。
- 已打三处补丁（仅在该环境变量下生效）：`gen_esp32part.py` 的 stdout 兜底、
  `CheckSourceCompiles.cmake`、`CMakeDetermineCompilerABI.cmake` + `CMakeTest{C,CXX}Compiler.cmake`。
- 若 `.a` 报 `file format not recognized`，说明是 PowerShell 链构建的产物，
  `find /d/p4c5build -name "*.a" -delete` 后 bash 链重链即可。
- 已生成：`esp32-p4c5-demo.bin` 713KB（分区余量 91%）、`bootloader.bin`、`partition-table.bin`。
  构建脚本 `build.sh` / 烧录脚本 `flash.sh` 已加入工程。
- 烧录待办：构建完成时 CH343（COM19）从系统消失（USB 断开），需重新连接后
  `bash flash.sh COM19`。
