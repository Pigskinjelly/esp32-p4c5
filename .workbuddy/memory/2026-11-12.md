# 2026-11-12 ESP32-P4C5 网络监控设备

## 环境（这台机器特有，必须照做才能编译）
- 构建必须由 **bash 作为进程树根**（`bash build.sh`）。PowerShell 启动的 cmake/gcc 产物会被
  TEC Ocular DLP 加密成 `%TSD-Header-###%`，导致 `junk at end of line`。
- 构建目录用 `/d/p4c5b2`（不要在桌面路径构建）。`TMP/TEMP=/d/idftmp`。
- `IDF_SKIP_TRY_COMPILE=1`（配合对 CMake modules 的补丁跳过 try_compile）；
  `CFLAGS/CXXFLAGS/ASMFLAGS=-pipe`；禁用 ccache。
- `ESP_IDF_VERSION=5.5`（不是 5.5.5）——esp_wifi_remote/esp_hosted 的 Kconfig 用
  `./idf_v$ESP_IDF_VERSION/` 拼路径，传 5.5.5 会让 Wi-Fi 相关选项被 orsource 静默跳过，
  表现为 `CONFIG_WIFI_RMT_* undeclared`。
- IDF 5.5.5 的 `tools/ldgen/ldgen.py` 已打补丁：objdump 经 cmd.exe 启动 + 校验
  `In archive`/`Sections:` 后重试，解决 DLP 导致的空输出/截断解析失败。

## 已确认的硬件事实
- P4 芯片 rev **v3.2** → sdkconfig 必须 `CONFIG_ESP32P4_REV_MIN_301=y`，
  否则 bootloader 报 "requires chip revision in range [v0.0 - v1.99]"。
- rev3 bootloader 约 24.7KB → 分区表偏移必须 `0x9000`（0x8000 只允许 0x6000）。
  分区：nvs 0xA000/0x5000、phy 0xF000/0x1000、factory 0x10000/8M、storage 7M。
- C5 为 **rev v1.2**，已烧 ESP-Hosted v2.12.9 合并包到 0x0（拨码拨到 C5 才能烧）。
- P4↔C5 SDIO：P4 GPIO14/15/16/17 = D0-D3、GPIO18 = CLK、GPIO19 = CMD、GPIO54 = C5 复位。
  hosted 组件的 `ESP_HOSTED_P4_C5_CORE_BOARD` 预设是**乐鑫官方板**（CMD=51/CLK=50），
  与本板不符，必须手填 `PRIV_SDIO_PIN_*_SLOT_1`。且 `CONFIG_SLAVE_IDF_TARGET_ESP32C5=y`
  必须先于 `CONFIG_ESP_HOSTED_CP_TARGET_ESP32C5=y`，否则 CP 目标退回 esp32。

## 踩过的坑（已修）
- `MIPI_DSI_PHY_CLK_SRC_DEFAULT` 是 rev<3.0 的别名（=PLL_F20M），rev3 上传入会走 HAL
  的 `default: abort()`。必须用 `MIPI_DSI_PHY_PLLREF_CLK_SRC_DEFAULT`（=XTAL）。
- `esp_codec_dev_cfg_t` 必须显式 `.dev_type = ESP_CODEC_DEV_TYPE_IN_OUT`，
  否则为 0(NONE)，`esp_codec_dev_new()` 返回 NULL。
- RTSP 前必须先 `esp_netif_init()` + `esp_event_loop_create_default()`，否则 lwip
  `tcpip_send_msg_wait_sem` assert (Invalid mbox)。
- **PPA 缩放精度只有 1/16**（SCAL_X_FRAG 是 4 位）。480/800=0.6 会被截断为 9/16=0.5625，
  输出只有 450x450 → 屏幕右侧/下方黑边。解法：中心裁 768x768（k=10）后按 0.625 缩放，
  输出正好 480。实测 bbox 从 x=0..449 变为 x=0..479。
- `esp_wifi_remote` 的注入头 `idf_v5.5/include/injected/esp_wifi_types_generic.h` 缺
  `gtk_rekey_interval`，导致 esp_hosted 编译失败 → 已本地补该字段。

## 19:45 第八轮：拍照链路修复 + 手势改为按键 + 控制中心全屏半透明

### 1. 拍照存不了 / 画质差 —— 根因是 JPEG M2M 用法错误
旧 app_jpeg.c 用 MMAP 输出缓冲且**从不 DQBUF 回收 OUTPUT 缓冲**，第二次起 QBUF 拿不到空闲缓冲
→ 编码失败（照片存不了）。相机 App 只报"保存失败"没细节。
重写为官方 uvc 例程的用法：
- OUTPUT：V4L2_MEMORY_USERPTR，直接指向 PPA 快照缓冲（零拷贝，省 1.28MB memcpy）
- CAPTURE：MMAP 一块；出队后**先不归还**，下次编码前再 QBUF
- 每次编码后 DQBUF 回收 OUTPUT 缓冲（必须）
- 质量用 VIDIOC_S_EXT_CTRLS + V4L2_CID_JPEG_CLASS 设 95（RGB565 输入默认 YUV422 子采样）
实测（开机自检日志）：`jpeg ready 800x800, quality=95` / `jpeg 800x800, 114 KB, SOI/EOI=ok`
/ `write 117432/117432 bytes` —— 全链路 OK。

### 2. 相册不显示 —— 读文件被截断
`app_storage_read_photo(..., 300*1024)` 硬上限 300KB，800x800 q95 约 117~350KB，
截断后 esp_jpeg_decode 必然失败。改为：新增 app_storage_photo_size()（stat），
缓冲 2MB PSRAM，读完后比对大小，不足则明确报"文件读取不完整"。
另加 lv_image_set_antialias(true)，缩小显示不再锯齿。
