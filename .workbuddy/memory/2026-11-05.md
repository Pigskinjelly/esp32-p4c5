# 2026-11-05 工作日志

## 项目：ESP32-P4C5 整机 demo（屏幕+相机+音频）

### 关键结论（已确认）
- 实物板卡 = **V1.5**，核心板 = **ESP32-P4C5-Core**（ESP32-P4 + ESP32C5HF4）。
- P4 主频 **400MHz**（HP）/ 40MHz（LP）；Flash 16MB + PSRAM 32MB（叠封）。
- P4 strapping：GPIO34(JTAG)、GPIO35/36/37/38(启动模式)；SPI Boot = GPIO35 高（默认弱上拉）。
  下载模式 = GPIO35 低 + GPIO36 高（底板上 GPIO36 有 R24 10K 上拉到 3V3）。
- 模块 88 脚；第 66 脚 = ESP_LDO_VO4（LDO 输出 0.5~2.7V/3.3V，200mA）。
- C5 strapping：GPIO26/27/28（启动模式）、GPIO25（打印控制）。

### 已核实的引脚映射（V1.3/V1.5 底板 P4 侧一致）
- I2C：GPIO7=SDA、GPIO8=SCL（共享：触摸+ES8311+相机 SCCB 经 TXS0102 转 1.8V）
- I2S0：GPIO9=DSDIN(TX→codec DAC)、GPIO11=ASDOUT(RX←codec ADC)、GPIO10=LRCK、GPIO12=SCLK、GPIO13=MCLK
- LCD：GPIO5=RST、GPIO4=TE、GPIO20=背光(LEDC)、GPIO21=TP_INT、GPIO6=TP_RST；DSI 2-lane(34-39)
- 相机：GPIO26=CSI_RST(必须开漏、1.8V 域)、CSI 2-lane(41-46)、MCLK=24MHz(X1 独立晶振)
- TF 卡 SDIO：GPIO39-44=D0-D3/CLK/CMD、GPIO45=DET；均 10K↑3V3
- 音频 PA：GPIO53=NS4150B STD；麦克风=板上 LMA3729 模拟麦
- USB：DP/DM(48/49) → TS3USB221A 自动切换(由 VIN2_5V 有无控制，软件不可控)
- 调试 UART0：GPIO37=TX、GPIO38=RX（CH343 → Type-C J7）

### 硬件缺口（用户确认只有开发板）
- 无屏（J3 需 YDP400BT001-V4 30P 0.5mm）、无相机（J1 需 SC2336 24P）、无喇叭（J9）。
- 板上自带的只有：ES8311 codec、NS4150B 功放、LMA3729 麦克风。

### 已确认的物料与外设
- 屏：4.3" 480x800 MIPI（驱动 IC = **ST7102**，触摸也是 ST7102，非 GT911），料号 YDP430BT009-V1。
- 相机：SC2336（2MP，24P 0.5mm，AVDD2.8/IOVCC1.8/DVDD1.5）。
- 喇叭：2415（8Ω/1W，2P-1.25 端子）。
- 天线：C5 双频 IPEX1 代（demo 用不到）。
- IDE：VS Code；ESP-IDF = **v5.5.5**（D:\Espressif，Python 3.11 venv）。

### 环境坑（WorkBuddy 内无法完成编译，需用户在 VS Code/自己终端编译）
- PowerShell 工具会向 gcc 读 sdkconfig.h 注入 `%TSD-Header-###%`+二进制垃圾（文件磁盘上干净，仅进程读到脏）。
- Bash(Git Bash) 里 `idf.py` 因 MSYSTEM 环境变量直接退出（不调用 main），且 MSYSTEM 无法 unset（MSys 运行时强加）。
- 二者都绕过后仍遇 cmake `try_compile` 临时文件"拒绝访问"（WorkBuddy 文件过滤层）。
- 结论：代码正确（组件下载/链接脚本/组件发现/Kconfig解析均通过），编译需在用户 VS Code ESP-IDF 终端执行。
- 可用 `cmd.exe //c build.bat`（Bash 工具里）触发组件下载 + Kconfig 解析验证（走到 try_compile 为止）。

### 远程音频监控 demo（本轮新增，无屏/相机/喇叭，仅开发板）
- 项目 `esp32-p4c5-audio-monitor/`：麦克风采集 -> WebSocket 推流 -> 浏览器 Web Audio 监听。
- 关键结论：**C5 通过 SDIO 连 P4**，P4 用 SDMMC SLOT1(GPIO14-19 走 GPIO矩阵)，与 TF 卡 SLOT0(GPIO39-44) 独立；C5 复位=GPIO54。
  - 注意：esp_hosted Kconfig 里 `P4_C5_CORE_BOARD` 预设的 SDIO 引脚是 GPIO48-53（错/旧版），实际核心板是 GPIO14-19，
    所以**不选板子预设**，显式设 `ESP_HOSTED_SDIO_PIN_CLK/CMD/D0-D3` = 18/19/14/15/16/17。
- esp_hosted 组件版本 2.12.13 + esp_wifi_remote 1.6.5；应用侧就是标准 esp_wifi API（透明转发）。
- **已知兼容坑**：esp_hosted 2.12.13 Kconfig 用 `$(ESP_IDF_VERSION) >= "6.1"` 宏（IDF 6.x 才有），IDF 5.5.5 会解析失败，
  需 patch managed_components/espressif__esp_hosted/Kconfig 那一行为 `depends on n`。
- C5 固件 = ESP-Hosted-MCU v2.12.9（devboard 仓库 firmware/ 下），esptool 烧 C5 0x0（开关拨 C5）。
- 组件：esp_hosted + esp_wifi_remote + esp_codec_dev；音频复用 esp_codec_dev 1.6.2 新 API。
